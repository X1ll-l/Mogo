# MoGo — Креативное дизайн-агентство

Адаптивный веб-сайт, созданный по мотивам дизайна MoGo Creative Agency.

Это мой учебный проект по Front-end разработке. Я создал его, чтобы практиковаться в HTML и CSS, улучшать навыки вёрстки и учиться создавать современные веб-сайты.
